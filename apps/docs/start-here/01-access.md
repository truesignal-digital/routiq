# Access the test environment

The ROUTIQ application is deployed at a demo URL with stable credentials. Both the URL and test account details are pinned in the team chat — check the pinned message before starting.

## Test workspaces

Two test workspaces are available for you to use:

- **TRUCKING** — the primary walkthroughs are written using this workspace; includes test data for a transport fleet of trucks and trailers.
- **PASSENGER** — a separate workspace for testing passenger transport operations with buses and minibuses. Same features and roles, different terminology.

Follow the walkthroughs using the TRUCKING workspace unless told otherwise.

## Language preference

The app supports both English and French. **While testing, use the English interface** — this is a team convention. English labels match the test documentation. To switch languages:

1. Click your username in the bottom-left sidebar.
2. Look for the language picker (usually a globe or flag icon).
3. Select English.

If you see French labels appearing where English is expected, that is a bug worth reporting.

## Login steps

1. Open the demo URL.
2. Enter your username and password (from the pinned chat message).
3. Choose a workspace (TRUCKING or PASSENGER).
4. You land on the Dashboard with your role and branch scope already active.

That's it — no two-factor authentication, no email confirmation. The test environment is open.
