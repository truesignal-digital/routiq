# Public disposable tester credentials

These credentials contain no real-user access and are intentionally published on
[`start-here/01-access.md`](./start-here/01-access.md). This file is excluded from the VitePress build
only to avoid publishing a duplicate page. They are the seeded demo accounts
(`apps/api/scripts/seed-demo.ts` and `seed-demo-passenger.ts` on develop).

Before real-user onboarding, remove these accounts or replace every PIN with a private credential.
